Point de Rosée · Privacy Policy

Last updated: 23 November 2026

"Point de Rosée publication" is a private tool used only by the owner of the YouTube channel Point de Rosée (@pointderoseeTV) to upload and schedule the channel's own short science videos. It is not offered to the public and has no other users.

What data the tool accesses

Through the YouTube Data API, the tool uses two permissions on the owner's own channel:

  • youtube.upload: to upload videos produced by the owner and set their title, description, tags and scheduled publication date.
  • youtube.readonly: to read the channel name and ID, only to confirm the tool is connected to the right channel.

The tool does not access, collect or store data about viewers or any other YouTube user.

How data is stored

The OAuth access token is stored only on the owner's computer, in a private folder readable by the owner alone. A local log keeps the ID and scheduled date of each uploaded video. No data is sent to any server other than Google's.

Sharing

No data is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes the tool's access.

Google and YouTube

This tool uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

Contact

For any question about this policy, contact the channel owner through the YouTube channel page above.
